# MRCET College Portal

A responsive demonstration website for Malla Reddy College of Engineering & Technology (MRCET). The project presents a modern college homepage with sample academic, campus, placement, event, and student-directory content.

## Features

- Responsive college landing page
- Programme and campus-life sections
- Sample student directory search by roll number or name
- Campus image lightbox and virtual tour dialog
- Placement and career studio section
- Mobile navigation menu
- Local image assets and custom CSS styling

## Project Structure

- `index.html` - Main page markup and content
- `app.js` - Student search, dialogs, lightbox, and interactive behavior
- `site.css`, `style.css`, `enhancements.css`, `placements.css`, `premium.css` - Page styling
- `assets/` - Campus and programme imagery
- `UserDom.java` - Java source included with the project

## Run Locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

This is a demonstration website and uses sample content for student records, admissions, events, and placement information.
